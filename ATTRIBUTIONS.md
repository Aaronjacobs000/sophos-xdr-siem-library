## Schema data

`studio/core/schema-data.js` is generated by `tools/build-schemas.mjs` from the public schema pages for Sophos NG-SIEM custom parsers on docs.sophos.com, and the type definitions (FileHash, KeyValuePairsIndexed, OperatingSystem and others) from the Taegis XDR custom parser docs (Secureworks, now a Sophos company). It holds field names, types, parser field names and enum names only. Read the linked schema pages for what each field means.

## Library samples

Every sample in `parsers/` is synthetic. Each entry's `meta.json` links the public vendor documentation its log format follows.

## Code

Parser Studio has no runtime or build dependencies. The emulator, the Go regex and time layout handling, the JSONPath reader and the ZIP writer are written for this project.
