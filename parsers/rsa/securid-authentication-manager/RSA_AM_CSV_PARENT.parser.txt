# Emulator result, not run in Sophos NG-SIEM. Test with Parse Message and Run Test before you turn it on.
# Source: RSA Authentication Manager 8.x audit and system logs forwarded to a remote syslog
# host. After the syslog header each line is comma-separated fields in fixed positions, from
# RSA's field map (KB 000059083, Syslog data explained):
#   1 IMS server local time, 2 milliseconds, 3 server name (often blank), 4 category (the
#   logger name), 5 log level, 6 event ID, 7 IMS server instance, 8 client IP, 9 server IP,
#   10 action key, 11 action ID, 12 result, 13 reason, 14 session ID, then fields that depend
#   on the category: runtime audit (40 fields), admin audit (32) or system log (27).
# Parent: splits the fields and hands runtime audit lines (authentication) to the Auth child,
# and admin audit and system log lines to the CloudAudit child.
# Position N of RSA's map is f[N - 2] here, since the time and milliseconds come off first.
