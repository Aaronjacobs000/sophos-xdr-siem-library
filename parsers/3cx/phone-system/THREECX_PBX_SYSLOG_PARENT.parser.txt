# Emulator result, not run in Sophos NG-SIEM. Test with Parse Message and Run Test before you turn it on.
# Source: 3CX Remote Syslog (Admin > Integrations > Remote Syslog, Custom Syslog Server), RFC 5424
# (the default) or RFC 3164, over syslog to the data collector.
# Parent: recognizes the JSON records 3CX sends with the EventLog tag and hands the security
# events to its child. Other EventLog records stay in the generic schema. AuditLog and
# Telemetry records aren't matched: 3CX doesn't publish their format.
# !TRIMALLOFF stops TRIM_ALL() stripping braces from JSON values.

hdr = originalData$|^<\d{1,3}>(?:1\s+\S+|[A-Z][a-z]{2}\s+\d{1,2}\s+\d{2}:\d{2}:\d{2})\s+(?P<host>\S+)\s+EventLog
jsonMatch = originalData$|(\{.*})\s*$
json = JSON(jsonMatch[1])

# Variables and $ fields set here are visible to the child.
sensorType$ = "3CX"
hostId$ = hdr["host"]
eventType$ = STRING(json["$.event_id"])
# The record's own time is UTC with seven decimal places.
eventTimeUsec$ = DATETIME(json["$.timestamp"], "2006-01-02T15:04:05.9999999Z07:00")
