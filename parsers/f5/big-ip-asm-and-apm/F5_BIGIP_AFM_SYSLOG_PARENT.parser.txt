# Source: F5 BIG-IP AFM network firewall and DoS events from a security logging profile's log
# publisher, in one of three keyed layouts:
#   Remote Syslog, rfc5424: <PRI>1 <time> <host> tmm <pid> <msgno> [F5@12276 key="value" ...] <text>
#   Splunk: key="value",key="value",... (a Remote High-Speed Log sends no syslog header)

# Parent: reads each layout into the same variables. Values are read key by key, because some,
