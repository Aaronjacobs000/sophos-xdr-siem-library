# Parser Studio 0.1.0: https://github.com/Aaronjacobs000/sophos-xdr-siem-library
# Emulator result, not run in Sophos NG-SIEM. Test with Parse Message and Run Test before you turn it on.
# Source: Trellix Network Security (NX, formerly FireEye NX) and Central Management CEF
# notifications (fenotify rsyslog, format cef) to the data collector:
#   <164>fenotify-88.alert: CEF:0|Trellix|MPS|10.0.1.997401|MC|malware-callback|7|...
# The vendor field is FireEye up to release 9 and Trellix from release 10. The product is MPS for
# Network Security and CMS for Central Management.
# Parent: hands each notification to a child by its event type code (the signature id field).
#   IE ips-event, MC malware-callback, DM domain-match, IM infection-match,
#   RC riskware-callback, RI riskware-infection                        to the NIDS child
#   MO malware-object, WI web-infection, RO riskware-object            to the third-party alert child
#   SmartVision and other types stay in the generic schema.

v = CEF(originalData$)
code = UPPERCASE(STRING(v[4]))
evName = STRING(v[5])
sevText = STRING(v[6])

# Variables and $ fields set here are visible to both children.
sensorType$ = "Trellix Network Security"
eventType$ = "other"
eventType$ = IF code == "IE" OR code == "MC" OR code == "DM" OR code == "IM" OR code == "RC" OR code == "RI" THEN "network" ELSE eventType$
eventType$ = IF code == "MO" OR code == "WI" OR code == "RO" THEN "object" ELSE eventType$
appliance = STRING(v["dvchost"])
hostId$ = IF appliance != "" THEN appliance ELSE NULL

# rt is the alert time, for example "Oct 16 2020 14:36:16 UTC". Trellix sends UTC unless the
# appliance is set to local time, which this parser doesn't cover.
rt = STRING(v["rt"])
rtm = rt|^(?P<t>[A-Z][a-z]{2} +\d{1,2} \d{4} \d{2}:\d{2}:\d{2})(?: (?:UTC|GMT))?$
eventTimeUsec$ = IF rtm["t"] != "" THEN DATETIME(rtm["t"], "Jan _2 2006 15:04:05") ELSE eventTimeUsec$
