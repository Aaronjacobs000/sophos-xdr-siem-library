# Source: nginx error log lines, sent with error_log syslog:server=<collector> (tag nginx, facility
# local7) or forwarded from the error log file by the host's syslog daemon. nginx documents the
# levels and the syslog target but not the line, so the layout follows its source (ngx_log.c,
