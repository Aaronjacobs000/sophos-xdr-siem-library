# Source: Qualys VMDR detections from the Host List Detection API, read by the example bridge in

# under HOST, the detection's under DETECTION and the QID's KnowledgeBase entry under KB, every value
# as the XML's text. The bridge sends a detection each time its status changes.
# Standalone: every detection to the third-party alert schema. Sophos Fusion has no vulnerability
# schema for custom parsers, and its schema list puts alerts from sources outside Sophos Fusion in
# Third Party Alerts.
# !TRIMALLOFF stops TRIM_ALL() stripping braces and brackets from JSON values.

alertId$ = json[d + "UNIQUE_VULN_ID"]
qid = STRING(json[d + "QID"])
# A detection carries only its QID. The bridge adds the KnowledgeBase title, unless QUALYS_KB=0.
