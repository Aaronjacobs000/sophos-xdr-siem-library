# Source: Cisco Webex admin audit events, security audit events (sign-ins and sign-outs) and Webex
# Calling detailed call history, pulled by the example bridge in bridges/webex-audit-and-call-history
# and posted to HTTP Ingest as JSON lines. The bridge puts "webex_record" first (admin_audit,
# security_audit or cdr).
# Parent: hands sign-ins and sign-outs (security audit events, and admin audit events in the LOGINS
# and LOGOUT categories) to the Auth child, other admin audit events to the CloudAudit child, and call
# records to the call CloudAudit child.
# !TRIMALLOFF stops TRIM_ALL() stripping braces and brackets from JSON values.

json = JSON(originalData$)

# Variables and $ fields set here are visible to every child.
sensorType$ = "Cisco Webex"
kind = json["$.webex_record"]
cdr = kind == "cdr"
# The API's examples write categories as EventCategory.LOGINS; Webex's records and the security audit
# example write LOGINS. Both are read.
cat = REPLACE(STRING(json["$.data.eventCategory"]), "EventCategory.", "")

# Times are ISO 8601 in UTC, such as 2019-01-02T16:58:36.845Z: created for audit events, and the
# call's Start time for call records.
